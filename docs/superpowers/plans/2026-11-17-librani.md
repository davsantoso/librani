# Librani Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Membangun Librani (sistem informasi perpustakaan, P0 + semua P1 dari PRD) dengan PHP native + MySQL, berjalan di XAMPP lokal dan InfinityFree.

**Architecture:** Satu file PHP per halaman di `modules/<grup>/<modul>/`, masing-masing `require` `includes/init.php` (config, PDO, session, helpers, auth, CSRF). Semua aturan bisnis sirkulasi ada di `includes/sirkulasi.php` dan `includes/reservasi.php`; halaman hanya memanggil fungsi. Logika diuji dengan skrip CLI berbasis assert pada database `librani_test`; halaman diuji dengan smoke test HTTP per role.

**Tech Stack:** PHP 8.2+ (lokal XAMPP PHP 8.5), MariaDB (XAMPP) / MySQL-MariaDB (InfinityFree), PDO, Bootstrap 5.3.3, Bootstrap Icons 1.11.3, jQuery 3.7.1, DataTables 2.1.8, Chart.js 4.4.6, SweetAlert2 11.14.5, SheetJS 0.18.5, JsBarcode 3.11.6, qrcodejs 1.0.0, html5-qrcode 2.3.8, Dompdf 3.x (Composer).

**Spec:** [docs/superpowers/specs/2026-11-17-librani-design.md](../specs/2026-11-17-librani-design.md) dan [prd_librani.md](../../../prd_librani.md). Baca keduanya sebelum mengerjakan task mana pun.

## Global Constraints

- PHP: kode kompatibel **8.2+**; jangan pakai fitur yang baru ada setelah 8.2 (mis. typed class constants, `json_validate`, `#[Override]`). Lokal berjalan di PHP 8.5, jadi deprecation 8.5 juga harus bersih.
- Semua tabel InnoDB, `DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci`. Dilarang `utf8mb4_0900_ai_ci` dan fitur khusus MySQL 8.
- Setiap tabel: `id INT AUTO_INCREMENT PRIMARY KEY`, `created_at DATETIME DEFAULT CURRENT_TIMESTAMP`, `updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP`.
- Semua query lewat PDO prepared statement. Nama tabel/kolom dinamis hanya dari literal di kode, tidak pernah dari input.
- Semua output dari DB/input lewat `e()`.
- Setiap form POST memakai `csrf_field()`; setiap handler POST memanggil `csrf_check()` pertama kali.
- Setiap halaman terproteksi memanggil `require_role(...)` sebelum output apa pun. Belum login → redirect ke login; role salah → 403 "Akses ditolak".
- Pola POST: validasi → simpan → `flash()` → `redirect()` (PRG).
- Penyimpanan yang menyentuh lebih dari satu baris dibungkus `db()->beginTransaction()` / `commit()` / `rollBack()`.
- Status eksemplar hanya diubah oleh fungsi di `includes/sirkulasi.php`/`includes/reservasi.php`, kecuali "tandai rusak/hilang" manual oleh petugas.
- Semua URL dibangun lewat `url()` dari `BASE_URL`; tidak ada path absolut tertulis langsung.
- Library front-end disimpan di `assets/vendor/`, tidak memakai CDN saat runtime.
- Format nomor: `PJM-YYYYMMDD-NNNN`, `KMB-YYYYMMDD-NNNN`, `BYR-YYYYMMDD-NNNN` (kuitansi denda), `AGT-YYYY-NNNN`, eksemplar `BK` + id buku 4 digit + `-` + urut 2 digit.
- Teks UI berbahasa Indonesia. Rupiah ditulis `Rp3.000`.
- Fungsi yang bergantung tanggal menerima parameter `?string $tanggal = null` (default `hari_ini()`), supaya tes dan seeder bisa memakai tanggal mundur.
- Commit per task, pesan gaya `feat: …` / `fix: …`, diakhiri `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Eksemplar yang sama dipilih dua kali, atau sudah dipinjam orang lain saat form disimpan** (form basi) → seluruh transaksi ditolak dan tidak ada yang berubah. Tes di Task 12.
2. **Pengembalian sebagian** (2 dari 3) → header tetap `aktif`, baru `selesai` setelah semua kembali; mengembalikan detail yang sudah kembali ditolak. Tes di Task 14.
3. **Admin mengubah `denda_per_hari` saat pinjaman sedang berjalan** → denda pinjaman lama tetap memakai tarif saat dipinjam. Kembali tepat di hari jatuh tempo → denda 0. Tes di Task 14.
4. **Anggota berstatus menunggu/kedaluwarsa, atau role salah, membuka URL halaman lain secara langsung** → 403 atau pesan "Akun menunggu verifikasi", tidak pernah melihat data. Tes di smoke Task 2 dan diperluas di setiap task UI.
5. **File upload palsu** (PHP yang diganti nama menjadi `.jpg`, file > batas, PNG asli 3000 px) → yang palsu/kebesaran ditolak dengan pesan; yang asli dikecilkan ke 600/200 px. Tes di Task 3 dan Task 7.
