# Daftar Foto Sampul Data Contoh

Simpan foto sampul setiap buku di folder ini dengan nama file sesuai kolom **File** (format JPG, PNG, atau WEBP; maks. 2 MB; ekstensi bebas, misal `BK0001.jpg` atau `BK0001.png`).
Setelah itu jalankan `php database/seed.php` agar foto dikecilkan otomatis (600 px + thumbnail 200 px) dan disalin ke `uploads/cover/`, lalu export ulang `database/librani.sql`.
Buku yang fotonya belum ada tetap tampil dengan sampul pengganti berisi judul.
